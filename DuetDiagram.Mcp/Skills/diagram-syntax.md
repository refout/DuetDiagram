# DSL 语法从哪看

这份图有一套自己的文本格式。人工不直接写它，模型要整段地生成或者读一份图时才用得上。

## 什么时候需要

- 要一次性产出一整张图，而不是一步一步发命令的时候。
- 手上有一份别处来的文本，要核对里面某个写法到底算不算数的时候。

猜出来的写法不会被拒绝，它会被当成**另一个**东西。所以拿不准就去查，别试。

## 去哪看

- **语法本身与完整示例在 `skill://diagram-syntax/dsl` 这一份资源文件里。先取它再动手。**
  这里不重复语法：写法一旦分两处，两处迟早对不上，而照着过期的那一处写出来的东西
  不会有任何地方报错。
- 那份文件里除了语法还带着「已定的默认值」与「映射阶段的规则」两节。前者是取值不是偏好，
  后者讲的是从文本到图的中间那几步里会发生什么转换——写的时候踩到的那几种歧义都在那里。
- 每条语法只有**一种**写法。看到两种都能通的时候，其中一种一定不是这套语法的。

## 与导出的关系

从图导出成文本这个方向还没有实现。现在能拿到的只有另一种格式的导出，
它是有损的：写不出去的东西会在返回里逐类列出。
