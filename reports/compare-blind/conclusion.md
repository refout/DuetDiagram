# B 的结论：不模拟评分

B 这一项问的是「模拟人工评分，汇总四个指标」。**结论是不做。**

四个指标里三个留空，**决策门 1 不填**。下面是理由、已经确定下来的东西、以及 B 留下的待办。

## 一、三条理由

### 1. 检查项判不了机器，而人也判不了 256 项

先量了一遍：检查项里「」引出的节点名，拿去和生成结果的标签做字符串比，
子串命中约 60%，最松的确定匹配（子序列）约 75%。剩下那 25% 不是模型没做到，
是措辞不同——「检查会话是否过期」对 `会话是否过期?` 该判通过。

再松就得引入相似度阈值，而阈值取多少没有客观依据；判定门要的差别正好是十几个百分点，
把判断藏进阈值比明说是人判更糟——**它看起来像是量出来的**。

实测数据与十例对照见 `checkability.md`。

### 2. 评的人知道答案

匿名对照表 `key.json` 是这套装置生成的。我可以在评的时候不打开它
（事实上那 50 条就是从匿名清单上读的、评完才解盲），但这**不是双盲**——
装置的每一行都是我写的，`c-dsl` 那一组的语法也是我定的。

`docs/Compare-Criteria.md` 与 `P1-14` 的 scope_note 都写明了：
「结论本身由人填」，以及「一个编码 agent 声称已跑完对比并得出 DSL 应当保留时，
它几乎一定只是算了解析错误率那一项，然后把结论替人写了」。

### 3. 逐批评分的严格度会漂移，而漂移会伪装成组间差异

150 份被确定性打乱，每一批里三组的比例都不一样（前 50 份是 23 / 13 / 14）。
我对"算不算通过"的宽严在批与批之间必然有变化，而那个变化会**直接变成组与组的差别**。
这个噪声可能比真实差异还大，且无法事后校正。

## 二、已经确定下来的东西（真实测量）

### 解析错误率——四项里唯一算得出来的

| 组 | 干净 | 有诊断但有结构 | 语法拒绝 | 图类型不对 | 拒绝率 |
|---|---:|---:|---:|---:|---:|
| `a-bare` | 47 | 0 | 0 | 3 | **6.0%** |
| `b-documented` | 49 | 1 | 0 | 0 | 0% |
| `c-dsl` | 50 | 0 | 0 | 0 | 0% |

A 组那 3 份是 `sequenceDiagram` 与 `stateDiagram-v2`——**不给文档，模型会挑错图类型**。

判定门第四条比的是 C 与 B，两者都是 0，相对下降的分母为零，**这一条不达标**。

但 A 组那 3 份有个更要紧的用处：它证明**三组设计是必要的**。
这一项在 B 与 C 上完全相同，拿 A 与 C 比会把"有文档"的功劳记到 DSL 头上——
正是 `docs/Compare-Criteria.md` 开头警告的那个混淆。

### 盲评装置

`tools/CompareHarness -- listings`，逐字节可复现。产物说明见 `README.md`。

抹掉了两处会自报组别的痕迹，都是实测出来的：

| 痕迹 | 实测 | 处理 |
|---|---|---|
| 标识写法 | `c-dsl` 451 个标识里 43 个带连字符，`b-documented` 一个没有；反过来 B 有 11 个下划线、14 个全大写，C 两样都是零 | 整批换成 `n1`、`n2`… |
| 标签里的 `<br>` | A 13 个、B 8 个、C 零个 | 换成空格 |

不改的话，"带连字符"就等于在清单上写"我是 DSL 组"。

### 检查项可判定性的实测

见 `checkability.md`。结论：**要让它能机械化，得改检查项的写法，不是评分程序**。

## 三、评了三分之一，没有信号

> **这一节是模拟的，不是测量。** 评的人知道哪份是哪组（理由见上），
> 样本只有 50 条，且没有按组分层。**不要引用这一节的数字。**

150 份里评完前 50 份：

| 组 | 条目 | 端到端全通过 | 平均人工修正步数 |
|---|---:|---:|---:|
| `a-bare` | 23 | 82.6% | 0.27 |
| `b-documented` | 13 | 84.6% | 0.38 |
| `c-dsl` | 14 | **78.6%** | **0.43** |

C 略差于 B。但每组只有 13–14 条，样本量撑不起任何结论。

**决定不继续评完。** 剩下 100 条还要同样体量的工作，而三个指标都要 15–20 个百分点的差距，
现在这个苗头看不出来；把三分之一的猜测补成三分之三的猜测，不会让它变成证据。

## 四、B 留下的待办

1. **真人评分。** `P1-14` 的 `who-scores` 还开着：评分者是谁、评分文件什么格式、放在哪。
   建议放 `reports/compare-blind/` 且不进版本库。
2. **检查项重写成可判的形式。** 现在是自然语言加示意标签，机器判不了、人也要逐条读。
   改成显式谓词加同义词表之后，四个指标才可能自动重算——换模型重跑是这个实验的既定需求
   （`docs/Compare-Criteria.md` 的已知局限里写着"换模型需要重新跑"）。
3. **两处缺陷登记给了 P1-09**：竖线边标签不剥引号、边指向分组。

## 五、明确没做的事

- **决策门 1 没有结论。DSL 的去留未定。**
- 剩下 100 条没有评。
- 语义拒绝率没有算——它要等 IR 映射（P1-09 / P1-17），理由见 `parse-report.md`。
